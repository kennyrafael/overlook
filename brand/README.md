# Overlook brand assets

- `mark.svg`: the app mark, an "O" lens over three layered horizon bands (also `apps/web/public/favicon.svg`; use it for the desktop app icon).
- `logo-light.svg` / `logo-dark.svg`: mark + wordmark for light and dark backgrounds.
- `preview.html`: all versions side by side.

Colours: indigo `#6366f1` → `#4338ca`; bands `#8b93f5`, `#c7d2fe`, white; text `#1e1b4b`.
The wordmark uses live text (Inter / Segoe UI); convert it to outlines before print or store use.
Keep the mark distinct from Anthropic's Claude logo: no sparkles or starbursts, no Claude orange.
